# Data and publication boundary

Checked 25 September 2026: the [IrishMAN dataset card](https://huggingface.co/datasets/sander-wood/irishman) displays MIT metadata but also states research-only, non-commercial use in its copyright disclaimer. It includes a public-domain assertion. Those statements do not resolve the recorded redistribution ambiguity for this release.

Decision: no record-level IrishMAN data, feature vectors, record identifiers, notation or audio are included. Existing aggregate measurements are discussed with their scope and evidence status. The executable public inputs are generated artificial numbers. They are not substitutes for musical validation.

Authorised collaborators can run the same analysis against their existing local 48-record numeric export and its SHA-256 manifest. Obtaining access to the original data and establishing redistribution rights remain separate from software reproducibility. No automated download or reconstruction of the source archive is provided.

No website/player implementation, private correspondence, source-recovery material, provider credentials, raw provider logs or private Git history belongs in this repository. The MIT software licence does not override dataset terms. Original copyright attribution is retained; public GitHub ownership is visible.
